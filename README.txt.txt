Laboratorio HTML5

Esta tarea consiste en crear una página web básica utilizando HTML, HTML5 y CSS. 
El proyecto incluye una estructura semántica con etiquetas como header, nav, main, section, article, figure, figcaption y footer.

También se integran elementos de HTML5 como video, audio y canvas. 
El archivo style.css se utiliza para aplicar diseño visual a la página.

El proyecto fue visualizado en un navegador web y subido a GitHub como copia en línea segura.
